# PassCraft Studio

PassCraft Studio is a Senior Design cybersecurity project focused on password security and cybersecurity education for small businesses.

The goal of the project is to provide small businesses with free and easy-to-use tools that can help employees create stronger passwords and improve their understanding of secure credential practices.

## Planned Features

- Customizable password generator
- Two password generation methods
- Password strength analysis
- Brute-force time calculator
- Password data leak detection
- Educational materials about password security and other common business security practices

## Technologies

- Python
- Streamlit
- Visual Studio Code
- Git/GitHub
- Streamlit Cloud

## Project Structure

- `app.py` - Main Streamlit web application
- `generators/password_generator.py` - Password generator and customization
- `generators/passphrase_generator.py` - Passphrase generator
- `requirements.txt` - Python packages required for the project

## Project Scope

PassCraft Studio will focus on password generation, password security analysis, data leak detection, and cybersecurity education.

The project will not include:

- Password storage
- User accounts or authentication
- Integration with external password managers
- Enterprise-level deployment or scaling
- Mobile app development
